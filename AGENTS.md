# Repository rules

## Micro commits

- Keep each commit small and focused on one change.
- Write commit messages as a short, simple action after an area prefix:
  - `backend: <what changed>`
  - `cloud: <what changed>`
  - `frontend: <what changed>`
- If a change spans more than one area, split it into separate commits.
- Review the staged diff and run the relevant check before every commit.
